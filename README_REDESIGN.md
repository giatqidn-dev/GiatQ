# GiatQ PWA v0.2.2 — REDESIGN + FAST

Versi ini adalah kelanjutan v0.2.1 FAST, jadi optimasi checklist instant + batch sync tetap dipertahankan.

Perubahan visual utama:
- Identitas putih + biru langit GiatQ diperkuat.
- Dashboard progress dibuat lebih premium dan ringkas.
- Ringkasan Selesai / Belum / Total langsung terlihat.
- Kartu kegiatan lebih compact, jam menjadi pill di sisi kanan.
- Warna kategori dibedakan tanpa membuat UI ramai.
- Navigasi mobile memakai ikon SVG yang konsisten.
- Desktop mendapat sidebar/rail khusus agar tidak terlihat seperti layar HP yang dibesarkan.
- Halaman Laporan, Premium, Profil, Auth, dan modal ikut didesain ulang.
- Status sinkronisasi terlihat di header desktop/tablet.
- Service Worker cache dinaikkan ke v0.2.2 agar browser tidak terus memakai UI lama.

Backend yang direkomendasikan: GIATQ_CORE_v0.1.5_FAST_SYNC atau lebih baru.
