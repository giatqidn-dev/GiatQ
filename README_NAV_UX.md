# GiatQ PWA v0.3.3 — Navigation UX

Perubahan kumulatif dari v0.3.2:

- Modal Premium memakai logo GiatQ asli, bukan ikon diamond generik.
- Tombol **Keluar akun** langsung logout tanpa browser confirm.
- Hardware/touch Back dari KegiatanKU, Laporan, Premium, atau Profil kembali ke **Hari Ini** terlebih dahulu.
- Back pada dialog menutup dialog terlebih dahulu.
- Di Hari Ini, perilaku Back berikutnya kembali mengikuti Android/PWA normal.
- Cache service worker dinaikkan ke v0.3.3 agar update cepat terambil.

Backend tetap GIATQ Core v0.1.9 OWNER ACCESS; tidak perlu patch backend untuk perubahan ini.
