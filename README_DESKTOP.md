# GiatQ PWA v0.2.6 — Desktop Redesign

Versi ini membawa semua fix v0.2.5 dan menambahkan pengalaman desktop/laptop yang berbeda dari mobile.

## Desktop
- Sidebar lebar dengan label lengkap.
- Header desktop berbentuk top bar.
- Dashboard Hari Ini menjadi layout 2 kolom.
- Ringkasan Selesai/Belum/Total menjadi panel desktop.
- Kartu aktivitas 2–3 kolom sesuai lebar layar.
- Laporan memakai layout 2 kolom.
- Premium 3 kolom.
- Profil menjadi layout profil + pengaturan berdampingan.
- Modal berada di tengah layar.
- Halaman auth/registrasi menggunakan komposisi desktop dua sisi.

## Mobile
Layout mobile v0.2.5 dipertahankan.

## Backend
Tetap memakai GiatQ Core v0.1.6. Tidak perlu mengubah Apps Script.
